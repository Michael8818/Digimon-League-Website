Organizer: how to create the access token
  1. On GitHub, open Settings → Developer settings → Personal access tokens → Fine-grained tokens and choose Generate new token.
  2. Name it something like "League leaders" and pick an expiration date.
  3. Under Repository access, choose Public repositories (read-only). The token doesn't need any repository.
  4. Under Permissions → Account permissions, set Gists to Read and write. Leave everything else as is.
  5. Generate the token, paste it above, and choose Organizer. You'll then get a private link for each leader.
